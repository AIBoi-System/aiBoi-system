# Registros de decisão arquitetural

ADRs preservam contexto, alternativas e consequências de decisões difíceis de reverter.

| ADR | Decisão | Estado |
|---|---|---|
| [001](ADR-001-modular-monolith.md) | Monólito modular | Aceita como alvo |
| [002](ADR-002-fastapi.md) | FastAPI no backend | Aceita |
| [003](ADR-003-flutter.md) | Flutter no cliente | Aceita |
| [004](ADR-004-postgresql.md) | Avaliação inicial de PostgreSQL | Substituída |
| [005](ADR-005-rest-api.md) | API REST | Aceita |
| [006](ADR-006-feature-first-flutter.md) | Feature-first no Flutter | Aceita |
| [007](ADR-007-supabase-postgresql.md) | PostgreSQL gerenciado pelo Supabase | Aceita; em migração |

Uma mudança cria novo ADR e marca o anterior como substituído; não reescreve a decisão histórica.
