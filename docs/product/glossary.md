# Glossário AiBoi

Terminologia técnica da pecuária de cria padronizada para o sistema.

| Termo | Definição |
| :--- | :--- |
| **Animal (Bovino)** | Unidade individual do rebanho, identificada por um número de brinco ou chip. |
| **Propriedade** | Fazenda ou sítio rural onde as atividades pecuárias ocorrem. |
| **Lote** | Agrupamento de animais por categoria ou finalidade para facilitar o manejo. |
| **Pastagem** | Área total destinada ao pastejo dos animais. |
| **Piquete** | Divisão menor da pastagem para controle de rotação e lotação. |
| **Matriz (Vaca)** | Fêmea em idade reprodutiva destinada à produção de bezerros. |
| **Reprodutor (Touro)** | Macho destinado à reprodução (monta natural ou doador de sêmen). |
| **Bezerro(a)** | Cria recém-nascida até o momento do desmame. |
| **Pesagem** | Ato de medir a massa corporal do animal, essencial para cálculo de ganho de peso. |
| **Sanidade** | Conjunto de ações preventivas e curativas (vacinas, vermífugos, exames). |
| **Reprodução** | Ciclo que envolve cobertura, inseminação, gestação e parto. |
| **Movimentação** | Transferência de animais entre piquetes ou entre fazendas. |
| **Nascimento** | Registro de entrada de um novo animal no inventário via parto. |
| **Morte (Óbito)** | Baixa de um animal no inventário por causas naturais ou acidentais. |
| **Inventário** | Quantidade total de cabeças de gado ativas na propriedade. |
| **Atividade** | Tarefa de manejo realizada pelo usuário no sistema (ex: aplicar vacina). |
| **Alerta** | Notificação automática sobre vencimentos ou anomalias (ex: carência de remédio). |
| **Status Reprodutivo** | Estado atual da fêmea (Prenhe, Vazia, Apta). |
| **IATF** | Inseminação Artificial em Tempo Fixo. |
| **GTA** | Guia de Trânsito Animal (Documento legal de transporte). |
| **SISBOV** | Sistema Brasileiro de Identificação Individual de Bovinos. |
| **Unidade Animal (UA)** | Padrão de peso (aprox. 450kg) usado para calcular a capacidade do pasto. |
| **GMD** | Ganho Médio Diário de peso do animal. |
