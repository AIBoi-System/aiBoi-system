# Documentação de Produto AiBoi

Este diretório contém a documentação estratégica e de requisitos do AiBoi, servindo como a fonte de verdade para o escopo, visão e regras de negócio do sistema.

## Objetivo
O objetivo desta pasta é consolidar o entendimento sobre o que o produto é hoje (MVP) e o que ele pretende se tornar no futuro, garantindo que o desenvolvimento técnico esteja alinhado às necessidades dos produtores rurais de cria.

## Ordem de Consulta e Prioridade
Para definições de escopo imediato, o documento **mvp-overview.md** é a autoridade máxima. Para decisões de design e experiência, consulte **product-principles.md**. Caso haja dúvida sobre termos técnicos de negócio, recorra ao **glossary.md**.

## Diferença entre MVP e Visão Futura
O **MVP (Minimum Viable Product)** foca no gerenciamento zootécnico básico essencial para uma fazenda de cria. Funcionalidades avançadas como rastreamento via IoT, inteligência artificial e módulos financeiros complexos são delegados exclusivamente ao **future-vision.md** e não devem ser implementados ou prometidos na fase atual.
