# Princípios do Produto

Estes princípios são inegociáveis e devem guiar todas as decisões de design, priorização de recursos e desenvolvimento técnico do AiBoi.

## Simplicidade Antes de Complexidade
Sempre escolha o caminho com menos cliques e termos técnicos. Se um recurso exige um manual de instruções para ser usado, ele não está pronto para o AiBoi.

## Reconhecimento Antes de Memorização
O usuário deve reconhecer o que fazer através de ícones e cores padronizadas da pecuária, sem precisar memorizar caminhos ou nomes de menus.

## Operação Orientada por Tarefas
O aplicativo deve focar no que o produtor está fazendo **agora** (ex: Pesando, Vacinando, Movendo). A navegação deve refletir as tarefas do mundo real.

## Mobile-First e Offline-First
O AiBoi nasce no celular e deve ser 100% funcional no curral sem internet. A sincronização em nuvem é um benefício secundário que acontece em segundo plano.

## Baixa Carga Cognitiva
Minimize a quantidade de texto e dados desnecessários na tela. Use visualizações gráficas e cards para que o produtor entenda o status do rebanho num piscar de olhos.

## Feedback Imediato
Para cada ação do usuário (cadastrar um boi, mover um lote), o sistema deve dar uma resposta visual ou sonora clara de sucesso ou erro.

## Dados Confiáveis e Histórico Preservado
A integridade dos dados zootécnicos é sagrada. Uma vez registrado um evento (nascimento, óbito), ele deve ser preservado para garantir a rastreabilidade real ao longo dos anos.

## Expansão sem Poluir
Novos módulos (Financeiro, Reprodução) devem ser adicionados de forma que quem não os usa não seja incomodado. A interface deve ser adaptativa.
