# Decisoes

> Estado: documento indice.

Esta secao organiza as decisoes e especificacoes de decisoes do AiBoi. A fonte de verdade deve ser interpretada junto do [indice geral](../INDEX.md), da [especificacao mestra](../00-master/especificacao-completa-aiboi.md) e do codigo atual.

## Principios

- Distinguir claramente comportamento implementado, parcial e planejado.
- Evitar duplicar regras; referenciar o documento proprietario.
- Registrar mudancas relevantes no changelog e, quando necessario, em ADR.
